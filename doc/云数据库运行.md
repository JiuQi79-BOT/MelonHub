# 云数据库运行

更新日期：2026-10-20。本文说明显式选择 cloud 配置时，如何连接已有云 MySQL 并在本机运行 Java 后端和 Vite 前端。本分支同时保留 [local 配置](本地Docker运行.md)，两种入口不会自动切换。

按 `.env.example` 配置忽略文件 `.env`，设置 `SPRING_PROFILES_ACTIVE=cloud`、`TEST_DB_TARGET=cloud`，填写 `CLOUD_DB_*`、`TEST_DB_URL/USERNAME/PASSWORD` 和初始 `ADMIN_*`。正式库固定 `melonhub_rbac`，测试库固定 `melonhub_rbac_test`，测试入口必须与所选云入口一致。Flyway 前校验主机、端口、库名及 TLS。不要将真实配置写入文档或日志。

没有可用的专用 Redis 时设置 `CACHE_ENABLED=false`，Redis health 同步关闭，查询直接访问 MySQL，全局限流退回实例内，`cache=DISABLED` 是预期状态。启用缓存时须先核对 `REDIS_*` 配置与项目专用实例；本地一键脚本仍会按项目标签检查和管理 `melonhub-redis`，不要让它操作其他应用的 Redis。

```powershell
./scripts/start-all.ps1 -NoBrowser
./scripts/stop-all.ps1
```

也可双击根目录 `start-all.cmd`、`stop-all.cmd`。后端 `127.0.0.1:8080`、监控 `127.0.0.1:8081`、控制台 `http://127.0.0.1:5174`，端口占用时拒绝启动。源码或配置变化后先停再启，`-Rebuild` 强制打包，日志位于 `.local/logs/`。

需要 Java 17 或兼容 JDK、Maven、Node.js/npm。首次执行 `npm --prefix frontend ci --ignore-scripts`。Windows PATH 过长时，在当前终端缩短为 Node、Java、Maven、PowerShell 与系统目录，避免 cmd.exe 的 8191 字符限制。

IDEA 导入根 `pom.xml`，共享配置在 `.run/`；Backend 加载根 `.env`，Tests 使用云测试库。IDEA 图形运行按钮未实测。

Flyway 自动应用 V1–V6，结构与升级策略见 [数据库设计](数据库设计.md)。不执行实验初始化 SQL、不重建 Swarm、不修改其他应用数据库。云入口不可达时报错，不回退本地数据库。

```powershell
./scripts/test-backend.ps1
npm --prefix frontend test
npm --prefix frontend run build
mvn -f sdk/java/pom.xml -B -ntp test
Invoke-RestMethod http://127.0.0.1:8080/api/health
```

Redis 不可用或测试未覆盖缓存路径时，不能将其他测试通过解释为已验证缓存功能。本轮未重新验证云端连接。
