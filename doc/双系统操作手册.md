# MelonHub 与课程管理系统操作手册

## 1. 选择登录入口

| 系统 | 验收入口 | 使用身份 |
| --- | --- | --- |
| MelonHub 权限管理控制台 | 云服务器 TCP `5174`，本地开发使用 `127.0.0.1:5174` | 控制台管理员账号 |
| 课程管理系统 | 云服务器 TCP `18090` | 课程教师、学生或课程管理员身份 |

在验收现场使用已加入白名单的网络，浏览器直接访问服务器入口。对于 MelonHub，可先打开同一入口下的 `/api/health`，确认页面显示 JSON 健康结果。云服务器地址及账号由项目维护者提供。两个入口使用不同账号体系。控制台管理员的管理范围由平台管理员角色与部门、软件范围共同决定。课程账号的菜单和业务权限取决于 MelonHub 中的课程角色及权限，课程、教学班、组员等数据范围由课程平台根据业务关系校验。

## 2. 使用 MelonHub

1. 登录后先看概览和右上角健康状态。通过账号菜单修改密码，按需启用两步验证。
2. 在「组织与软件」查看部门、用户和软件。课程联调使用部门编码 `course` 与软件编码 `course-project-management`。进入对象的配置抽屉可直接维护同一授权域。
3. 在「授权管理」选择部门和软件。在所选部门或软件的配置抽屉中切换「角色」「权限」「用户授权」，核对编码、有效角色与到期时间。
4. 维护授权时，先确认顶栏选中的授权域，再编辑角色的权限或用户的分配。复验时重新进入该用户授权页面，核对角色、有效期和所属软件。
5. 用「权限诊断」输入目标用户和权限编码，核对预期允许和拒绝两个场景。「审计日志」用于查看授权变更记录及请求编号。
6. 超级管理员在「管理员账号」「管理员角色」维护控制台自身的访问能力。平台管理员管理业务配置，课程授权管理员管理指定的部门与软件，审计员查看授权与审计。切换账号时先退出原会话。

课程后端当前经 `/auth/me` 获取权限集合，再由本地授权组件判断操作；MelonHub 的 operationId 查询接口不是当前课程后端的必经链路，见 [实际接入核对](课程权限接入核对.md)。

## 3. 使用课程管理系统

1. 在课程平台登录页选择教师或学生身份，输入对应的工号或学号和密码。验收演示使用已准备的联调账号。
2. 教师进入课程工作区，选择学期和课程，查看有权访问的教学班、名单和里程碑。课程操作菜单随课程状态、角色和课程内身份变化。
3. 学生进入「我的课程」，打开已加入的课程和教学班，按课程配置查看里程碑、分组、提交入口和成绩。
4. 课程管理菜单使用已分配 `admin` 课程角色的身份登录。现场演示前可在授权域核对测试用户的课程角色及凭据状态。MelonHub 超级管理员账号对应的是权限控制台。
5. 验证联调时先用教师和学生各自登录，观察可见菜单与已分配角色。需要演示授权变化时使用专用验收账号，记录修改前的授权，演示后恢复。首次登录失败时依次确认课程业务身份已存在、MelonHub 统一身份凭据可用、角色归属正确。

## 4. 菜单请求日志演示

在 Swarm 管理节点先运行 `docker service ls`，确认权限系统与课程系统的前后端四个服务均可见且副本为 `1/1`。再运行以下命令。用已经登录的 MelonHub 控制台依次打开「用户」「系统状态」「审计日志」。打开浏览器开发者工具的网络面板，对应查看请求的状态及响应头 `X-Request-Id`。在后端日志中按相同编号定位一行，核对方法、路由模板、HTTP 状态与耗时。

```sh
docker service logs --since 2m --timestamps -f melonhub_melonhub-backend
```

例如 `GET /api/admin/users` 对应用户列表读取。权限页面需要先选中有效授权域。控制台内纯界面切换需要实际触发 API 请求才有对应的后端行。管理变更可同时通过控制台审计查看。

## 5. 现场定位

| 现象 | 核对位置 |
| --- | --- |
| 两个入口连接超时 | 当前公网出口是否在白名单，目标端口是否填写正确 |
| MelonHub 登录成功但菜单操作受限 | 管理员角色功能、部门和软件范围 |
| 课程账号登录失败 | 登录角色、课程本地身份、统一身份凭据、课程软件状态 |
| 课程账号看不到某个功能 | 课程角色是否授予菜单权限，以及该账号是否属于对应的课程和教学班 |
| 菜单日志找不到 | 网络面板是否发出请求，查看的是否为 MelonHub 后端容器，是否按同一请求编号查找 |

完整功能说明见 [MelonHub 使用说明书](使用说明书.md)，接口与权限范围见 [API 文档](API.md)。
