## 自动化验证说明

- 后端测试已全部重组为按需求编号（`r01`–`r34`、`architecture`、`shared`）分包，每个测试类顶部集中管理统一测试参数；Controller 契约测试全部在真实 MySQL 测试库（`melonhub_rbac_test`）上对 `structured` 与 `ddd` 双策略运行，Redis 缓存与全局限流专项测试在专用本地 Redis 容器上运行。详细执行结果见 [需求与测试矩阵](requirements.md#5-需求与测试代码对照矩阵) 与 [验证记录](验证记录.md)。
- 老师课程系统实际运行镜像已只读核对：通过 `/auth/me` 获取权限，未使用所讨论的三个 operationId；见 [课程权限接入核对](课程权限接入核对.md)。
