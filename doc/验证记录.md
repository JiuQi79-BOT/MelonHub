已实际执行 PowerShell 入口和根目录 CMD 入口，确认后台服务在启动脚本退出后仍可访问。

| 检查 | 结果 |

| 重复启动 | 复用已有项目实例，无重复后端或前端 |
| 正常停止 | 仅停止可确认归属项目的 Java / Vite 进程 |
| 重复停止 | 成功，无项目进程时安全退出 |
| 历史自动端口策略下，其他程序占用前端 5173 | 当时自动选择 5174，代理与数据库健康；现已按用户要求固定 5174 |
| 其他程序占用后端 8080 | 拒绝启动，不结束占用者 |

```json
{"status":"UP","database":"UP","model":"RBAC0"}
```

一键启停管理本机应用和它持有的数据库连接；不负责开关 ECS 或云端 MySQL，不会删除库或已保存的业务数据。最终服务保持运行，实际地址也可查看 `.local/services.json`。
