### 0.1 变更与修复

- 软件拥有角色，权限归属角色；角色编码在软件内唯一，权限编码在角色内唯一。部门仅管理成员与批量设置角色。
- 用户角色按软件查询、替换和追加；无部门用户可以授权、提交申请、获批并创建上下文；部门变化保留软件角色、期限和上下文。
- 角色成员、权限反查、复核快照、到期查询、搜索、概览和控制台同步新模型。具体权限的使用者按所属角色查询，不混入其他角色的同编码权限。
- 修复无部门申请的旧校验、LEFT JOIN 缺失、“全部成员”按部门 0 查询空列表、概览 SQL 参数数量及全局搜索部门空值等问题。
- 清单升级软件级 v2，移除跨部门复制；新业务接口使用软件路径，旧部门路径保留兼容。
- 删除本地 MySQL profile 和 MySQL/Redis 容器启停代码，一键脚本仅管理前后端。Redis 默认关闭，保留服务器缓存与限流能力。
