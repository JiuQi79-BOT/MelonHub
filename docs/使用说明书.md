# MelonHub 项目使用说明书

更新日期：2026-10-27。软件分别拥有角色和权限，角色可共享同一软件权限；部门仅用于成员管理、筛选及批量设置角色。结构见 [数据库设计](数据库设计.md)，接口见 [API](API.md)，配置见 [服务器部署与启动](服务器部署与启动.md)。

## 启停与登录

按 `.env.example` 配置忽略的根目录 `.env`。只使用云 MySQL，正式库 melonhub_rbac，测试库 melonhub_rbac_test。Redis 默认关闭，服务器部署后启用。

当前为 `BACKEND_MODE=server`：运行 `start-all.cmd` 或 `./scripts/start-all.ps1 -NoBrowser`，启动本机前端与 SSH 通道，访问 `http://127.0.0.1:5174`。运行 `stop-all.cmd` 或 `./scripts/stop-all.ps1` 只停止本机前端和通道，服务器后端继续运行。脚本不管理数据库、Redis 或其他程序。

本机配置变化后先停再启；后端源码或服务器运行配置变化后，先测试，再运行 `./scripts/deploy-backend.ps1`。服务器模式不支持 `start-all -Rebuild`；只有 `BACKEND_MODE=local` 的本机 Java 调试模式可在停止后用 `-Rebuild` 强制打包。日志在 `.local/logs/`，分享前核对脱敏。

初始管理员由 ADMIN_USERNAME/ADMIN_PASSWORD 创建；密码 12–100 字符且 UTF-8 不超过 72 字节，只在账号不存在时创建。账号恢复可由另一位超级管理员重置密码；本机 Java 模式也可临时设置 ADMIN_PASSWORD_RESET=true 重启一次，再改回 false。服务器部署工具固定关闭该开关，仅修改本机 `.env` 并重新部署不会重置服务器密码。五次登录失败锁定十五分钟；会话八小时、空闲三十分钟。账号菜单修改密码保留当前会话并结束其他会话；重置密码、修改角色、停用账号或启用、停用、重置两步验证会结束全部会话。

| 管理员 | 范围 |
| --- | --- |
| 超级管理员 | 全部配置及管理员账号 |
| 平台管理员 | 基础资料及全部软件授权 |
| 软件管理员 | 被授权软件的配置和治理 |
| 审计员 | 只读 |

## 从零配置

1. 在软件接入中创建软件，把一次性 API Key 保存到可信业务后端。
2. 打开软件配置抽屉，创建角色，编码在软件内唯一。
3. 创建软件权限，再为角色勾选保存。权限编码在软件内唯一，多个角色可勾选同一权限；也可在角色配置中创建新权限并勾选。
4. 创建用户，externalId 对应业务身份。部门可选，可以多个或没有部门。
5. 分配该软件角色，可设置统一天数或逐角色期限，空期限为永久。
6. 业务后端先认证用户，再创建上下文；每次受保护操作前在线校验权限编码，全部允许后执行业务操作。

有效权限是已激活、启用且分配未到期角色的权限编码并集。没有用户直接权限、角色继承、通配符或业务规则；resource/action 为元数据。API Key 不下发浏览器。

## 部门与批量授权

部门只组织成员。选择部门筛选人员，不产生另一套角色/权限；“全部成员”包含无部门用户。移出部门不删除软件角色和期限，切换部门不撤销上下文。

部门抽屉可维护成员并设置软件角色；软件抽屉统一维护角色、权限和成员授权。跨页选人后可对多个软件追加角色，已有有效分配及期限保留，每个软件分别反馈结果；个别用户可继续单独调整。

单用户保存替换该软件的全部角色并使该软件已有上下文失效，其他软件授权保留。部门与软件没有准入关系，不再提供跨部门配置复制。删除部门前移除成员；删除软件前处理角色与权限，冲突会提示数量。

## 控制台与治理

| 页面或入口 | 操作 |
| --- | --- |
| 权限概览 | 软件授权统计，部门筛选成员 |
| 部门、用户、软件 | 资料、成员、配置抽屉、用户导入、API Key、Webhook |
| 角色、权限、成员授权 | 软件角色、软件共享权限、成员、期限、权限反查 |
| 审批中心 | 批准/驳回角色申请，无部门用户也可申请 |
| 权限复核 | 按软件发起，可按当前部门成员筛选，逐项保留/回收后关闭 |
| 权限诊断 | 用户、软件和激活角色预演；部门可省略，不创建上下文 |
| 审计日志 | 查询、导出与 SHA-256 哈希链校验 |
| 系统状态 | MySQL、缓存、连接池；当前 cache=DISABLED 正常 |
| 管理员账号 | 超级管理员管理角色、范围、锁定、MFA |
| 接入指南 | 业务 API 与在线联调，部门可省略 |

同用户同角色仅一条待审批申请。批准可设置天数或永久。复核保存当次 grant_id；期间续期或重新授权后，关闭复核不会误删新的分配，会记为跳过；未决定条目保留。

到期立即不再计入权限，每分钟清理任务和通知可能晚约一分钟。角色启停、权限变更下一次校验生效；重新分配、审批、复核回收撤销对应用户在该软件的上下文。

## 清单、密钥和审计

角色页导出整个软件的 v3 清单，每条权限只定义一次。导入按软件内角色编码和权限编码匹配，更新列出的角色配置，保留用户分配及期限；共享定义的修改影响所有引用角色。旧 v1/v2 清单需转换或升级后重新导出。普通列表可导出 CSV。

每软件最多十个有效 API Key，支持期限与单独吊销。计划轮换先建新密钥再吊销旧密钥；紧急轮换吊销全部旧密钥。Webhook 接收方先验 HMAC-SHA256 签名再清理缓存；失败最多重试八次，不能代替在线授权。

审计哈希链支持封存顺序与保留期锚点，但与数据同库，不代替外部存证。敏感凭据不写入审计。

## 常见问题

- 无部门用户可以授权和创建上下文，部门不是门槛。
- 同一软件的多个角色可引用同一条权限定义，修改共享定义影响所有引用角色；仅移除某角色的权限关联不影响其他角色。
- CONTEXT_INVALID 时重新创建 token；网络故障按拒绝处理。
- 云数据库不可达时检查网络、TLS 和凭据，不回退本地数据库。
- Redis 关闭时直接查云 MySQL，限流按实例执行。
- IDEA 配置位于 `.run/`，图形按钮未实测；Java SDK 为独立 Maven 工程。
