# 云数据库运行

更新日期：2026-10-26。MySQL 只连接已有云数据库。当前使用服务器 Java 后端与本机 Vite，操作见[服务器部署与启动](服务器部署与启动.md)；下文本机 Java 配置用于 `BACKEND_MODE=local` 开发与测试。启停脚本不创建、启动、停止数据库或 Redis 容器。

按 `.env.example` 配置忽略文件 `.env`，填写 `CLOUD_DB_*`、`TEST_DB_URL/USERNAME/PASSWORD` 和初始 `ADMIN_*`。正式库固定 `melonhub_rbac`，测试库固定 `melonhub_rbac_test`，测试入口必须与云入口一致。Flyway 前校验主机、端口、库名及 TLS，不允许 local profile。不要将真实配置写入文档或日志。

`CACHE_ENABLED=false` 为默认值，Redis health 同步关闭。服务器 Redis 部署后配置 `REDIS_HOST/PORT/PASSWORD/DATABASE` 并启用缓存。当前查询直接访问云 MySQL，全局限流退回实例内；`cache=DISABLED` 是预期状态。

```powershell
./scripts/start-all.ps1 -NoBrowser
./scripts/stop-all.ps1
```

也可双击根目录 `start-all.cmd`、`stop-all.cmd`。本节的 `BACKEND_MODE=local` 模式下，后端 `127.0.0.1:8080`、监控 `127.0.0.1:8081`、控制台 `http://127.0.0.1:5174`，端口占用时拒绝启动。修改本机配置后先停再启，停止后可用 `-Rebuild` 强制打包本机后端；前端源码由 Vite 自动加载。服务器模式的 8080 是 SSH 通道，不提供本机 8081 监控入口，后端更新使用部署脚本，日志位于 `.local/logs/`。

需要 Java 17 或兼容 JDK、Maven、Node.js/npm。首次执行 `npm --prefix frontend ci --ignore-scripts`。Windows PATH 过长时，在当前终端缩短为 Node、Java、Maven、PowerShell 与系统目录，避免 cmd.exe 的 8191 字符限制。

IDEA 导入根 `pom.xml`，共享配置在 `.run/`；Backend 加载根 `.env`，Tests 使用云测试库。IDEA 图形运行按钮未实测。

Flyway 自动应用 V1–V7，结构与升级策略见 [数据库设计](数据库设计.md)。不执行实验初始化 SQL、不重建 Swarm、不修改其他应用数据库。云入口不可达时报错，不回退本地数据库。

```powershell
./scripts/test-backend.ps1
npm --prefix frontend test
npm --prefix frontend run build
mvn -f sdk/java/pom.xml -B -ntp test
Invoke-RestMethod http://127.0.0.1:8080/api/health
```

服务器 Redis 尚未部署时，依赖 Redis 的集成测试会跳过，不能解释为已验证缓存功能。
