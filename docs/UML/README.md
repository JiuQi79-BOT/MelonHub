## 重建

源文件为同目录 `render.py`，使用 Pillow 和 Windows 微软雅黑字体。已具备 Pillow 的环境中，在项目根目录执行：

```powershell
python docs/UML/render.py
```

其他系统需要把脚本的 `FONT` 改为可用的中文字体路径。修改源码后重建并检查全部 PNG 的文字、箭头和边界，再随文档一起提交。
